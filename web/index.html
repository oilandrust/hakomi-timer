Hakomi practice

Timer for Android

A quiet timer for training groups. Plan the session, share the rounds, keep the phone awake while you practise.

Download the APK

Debug build · Android 8 or newer

On the phone, tap the file after it downloads. The first time, Android will ask you to allow installs from the browser.

If it does not install

  1. Open the downloaded file from the notification or your Downloads folder.
  2. Allow “Install unknown apps” for Chrome or your files app.
  3. If you already have a copy from another computer, uninstall that one first — debug builds from different machines do not overwrite each other.
